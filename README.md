# 3D Printers

Configuration files, macros, and slicer profiles for my 3D printers.

## Contents

- [`voron2.4/`](./voron2.4/) — Voron 2.4 (300mm) Klipper, Moonraker, Mainsail, KAMP, StealthBurner LEDs, and BedFans configuration.
- [`orcaslicer/`](./orcaslicer/) — Local OrcaSlicer configuration (`OrcaSlicer.conf`) and custom user presets (`user/default/{machine,filament,process}/`).
- [`scripts/sync_orcaslicer.sh`](./scripts/sync_orcaslicer.sh) — Helper script to diff and sync OrcaSlicer presets between the local Flatpak config directory and this repository.
- [`AGENTS.md`](./AGENTS.md) — Instructions for AI agents on repository conventions and two-way OrcaSlicer config syncing.
